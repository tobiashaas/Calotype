# Calotype — Research Foundations

Calotype predicts **Lightroom develop settings** (sliders, curves, masks) instead of rendering
pixels: every result is a list of values the photographer can read and change. This page lists the
published work behind what is built and what is planned, and what we take from each. Every entry
was checked against the paper (arXiv id, DOI or the authors' project page). Status: **used** = in
the code today, **planned** = on the roadmap (`TODO.md`, Phase 8).

Speed and accuracy figures for Calotype itself come only from our own measurements (`tools/eval/`,
`tools/lr_e2e/`, see CLAUDE.md); none are taken from these papers.

---

## 1. Parametric editing (sliders instead of pixels)

- **Hu, He, Xu, Wang, Lin — *Exposure: A White-Box Photo Post-Processing Framework*.**
  ACM Transactions on Graphics 37(2), 2018. arXiv:1709.09602.
  Retouching as a sequence of readable operations (exposure, curves, saturation …). *Used* as the
  principle: Calotype outputs editor settings, never pixels.
- **Moran, Marza, McDonagh, Parisot, Slabaugh — *DeepLPF: Deep Local Parametric Filters for Image
  Enhancement*.** CVPR 2020. Local parametric filters at any resolution; the idea behind using
  Lightroom's own AI masks with learned strengths (*used*, `masks.py`).
- **Bychkovsky, Paris, Chan, Durand — *Learning Photographic Global Tonal Adjustment with a Database
  of Input/Output Image Pairs* (MIT-Adobe FiveK).** CVPR 2011. The standard paired dataset; candidate
  training / test data (*planned*, licence to be checked for the intended use).

## 2. Learning a photographer's style from few examples

- **Saeedi, Hoffman, DiVerdi, Ghandeharioun, Johnson, Adams — *Multimodal Prediction and
  Personalization of Photo Edits with Deep Generative Models*.** AISTATS 2018. arXiv:1704.04997.
  Hierarchical model over many users' Lightroom-style slider edits, adapted per user. Formalises our
  pooled base model + per-photographer layer (*planned*, 8.2).
- **Kosugi, Yamasaki — *Personalized Image Enhancement Featuring Masked Style Modeling*.**
  arXiv:2306.09334 (2023). Style depends on the content of each photo, not one look for all
  (*planned*, 8.5).
- **Weldengus et al. — *RefRetouch: Personalized Image Retouching without Test-time Fine-tuning*.**
  arXiv:2602.17044 (2026). Retrieves the reference pairs closest in content to the query photo.
  *Used*: without a profile, shoot calibration blends a ridge fit with the three edited photos
  closest in content (`shoot.py`, measured with `tools/eval/shoot_lab.py`).
- **Bianco, Cusano, Piccoli, Schettini — *Personalized Image Enhancement Using Neural Spline Color
  Transforms*.** IEEE TIP 2020. A new user is placed in a learned user space from a few edited photos.

## 3. Training without expert edits

- **Ho, Zhou — *Deep Preset: Blending and Retouching Photos with Color Style Transfer*.**
  arXiv:2007.10701 (2020). Training pairs generated by scripting Lightroom with presets. Calotype can
  do the same with its own CC0 looks through `tools/lr_e2e` (*planned*, 8.2).
- **Goyal, Ruiz, Meisami et al. — *ATune: Unsupervised Photo Retouching Through Image-Editor
  Controls*.** arXiv:2611.16236 (2026). Learns from good photographs alone (damaged copies give the
  pairs) and sets the sliders of darktable / RawTherapee by search. Template for an own base model and
  for other raw converters (*planned*).
- **Ahn — *PREEN: Exemplar-Based Color Style Transfer with Smartphone Editor Presets*.**
  arXiv:2610.36896 (2026). Regresses a whole editor preset from a reference image, with one strength knob.

## 4. Consistent series

- **HaCohen, Shechtman, Goldman, Lischinski — *Optimizing Color Consistency in Photo Collections*.**
  ACM TOG (SIGGRAPH) 32(4), 2013. Photos that share content are linked in a graph; a quadratic cost
  over the graph makes them consistent, user edits are constraints. Maps directly onto Calotype: the
  edited examples are the constraints, the other photos of the shoot follow (*used*, first version: `series.py`,
  edit request `consistent_series`; thresholds not yet tuned on real shoots).
- **Liang, Zeng, Cui, Xie, Zhang — *PPR10K: A Large-Scale Portrait Photo Retouching Dataset with
  Human-Region Mask and Group-Level Consistency*.** CVPR 2021. arXiv:2105.09180. Portrait retouching
  with human-region priority and consistency within a group — the yardstick for weddings
  (*planned*, licence to be checked).
- **Barron, Tsai — *Fast Fourier Color Constancy*.** CVPR 2017. arXiv:1611.07596. A posterior over
  illuminants instead of one estimate, which allows temporal smoothing of white balance.

## 5. White balance across cameras and shoots

Absolute white balance does not transfer between shoots in our measurements; these address that.

*Used* so far: the camera's own illuminant estimate per frame (Canon `ColorTempMeasured`, read from the
RAW by the Bridge) is a feature for temperature in shoot calibration — the measurement the methods
below start from. A fixed offset to it did not work; the photographer's preference is learned from
the edited examples.

- **Afifi, Brown — *Deep White-Balance Editing*.** CVPR 2020. arXiv:2004.01354.
- **Afifi, Barron, LeGendre, Tsai, Bleibel — *Cross-Camera Convolutional Color Constancy* (C5).**
  ICCV 2021. arXiv:2011.11890. Calibrates to a new camera from unlabeled images at test time — we
  have the whole shoot (*planned*, 8.4).
- **Kim, Afifi, Kim, Brown, Kim — *CCMNet: Leveraging Calibrated Color Correction Matrices for
  Cross-Camera Color Constancy*.** arXiv:2504.07959 (2025). Uses the camera's colour matrices, which
  RAW / DNG metadata carry (*planned*).
- **Zhao, Afifi, Brown — *Learning Camera-Agnostic White-Balance Preferences*.** arXiv:2507.01342
  (2025). Maps a neutral correction to the preferred one with ~500 parameters — a photographer's
  "a little warmer" (*planned*, 8.4).
- **Cheng, Cui, Su, Gu, Zhang — *Perception-Inspired Color Space Design for Photo White Balance
  Editing*.** arXiv:2512.09383 (2025). White balance in a learnable HSI space that separates
  luminance from chroma.

## 6. Culling

- **Chang, Yu, Wang, Ashley, Finkelstein — *Automatic Triage for a Photo Series*.** ACM TOG
  (SIGGRAPH) 35(4), 2016. Quality relative to the other photos of a series, with human preference
  data. Calotype's culling features are series-relative already (*used*); the data set is a second
  yardstick (*planned*, 8.6).
- **Huang et al. — *Series Photo Selection via Multi-view Graph Learning*.** arXiv:2203.09736 (2022).

## 7. Image backbones and runtime

- **Qin et al. — *MobileNetV4: Universal Models for the Mobile Ecosystem*.** ECCV 2024.
- **Woo et al. — *ConvNeXt V2: Co-designing and Scaling ConvNets with Masked Autoencoders*.** CVPR 2023.

Candidates only: DINOv2, SigLIP and Perception Encoder features gave no gain over our hand features
(Model v2 in `TODO.md`); a backbone is tried again only together with the methods above. Local
inference is planned through ONNX Runtime (CoreML, CUDA / TensorRT, DirectML, OpenVINO, QNN, CPU).

Other tools' edits (Aftershoot, Neurapix) serve only as internal yardsticks: no data, weights,
presets or outputs derived from them go into Calotype.
